---

## 🌟 مميزات التطبيق
1. **تصميم احترافي تليجرام ستايل (Dark Violet Theme):**
   - خلفيات ليلية فخمة بلون البنفسجي والأسود الفاحم.
   - فقاعات رسائل متدرجة أرجوانية أنيقة.
   - مؤشر يكتب الآن ("حبيبي يكتب الآن... ✍️").
   - علامات قراءة الرسائل (✓✓) باللون البنفسجي.
   - إمكانية التفاعل مع أي رسالة بقلب رومانسي نابض (Double Tap ❤️).
2. **أمان تام وقفل التطبيق:**
   - **بصمة الإصبع (Fingerprint / Biometrics):** يطلب بصمة اليد فور فتح التطبيق.
   - **رمز PIN سري:** لوحة مفاتيح أرقام دائرية سريعة في حال تعذر البصمة.
3. **خاص وحصري لكما فقط:**
   - السيرفر مبرمج لقبول رقمين فقط (رقمك ورقمها).
   - لا توجد أي خدمات تتبع أو إعلانات أو أطراف خارجية.
4. **شات مباشر وسريع (Real-time WebSockets):**
   - الرسائل تصل فوراً في أجزاء من الثانية.

## 🌐 الخطوة 2: تشغيل واستضافة السيرفر (مجاناً)

### للتجربة السريعة على نفس شبكة الواي فاي:
- اضغط مرتين على ملف `server/run.bat`.
- هيتم تثبيت المكتبات وتشغيل السيرفر على: `http://localhost:8000`.

### لتشغيله عبر الإنترنت في أي مكان (4G / Wi-Fi) مجاناً 100%:
1. ارفع مجلد `server` على حسابك في GitHub (مستودع خاص Private).
2. افتح موقع [Render.com](https://render.com) (مجاني).
3. اضغط **New Web Service** واختر المستودع.
4. الإعدادات:
   - **Runtime:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `uvicorn main:app --host 0.0.0.0 --port $PORT`
5. مبروك! Render هيديك رابط سحابي مجاني مثل: `https://habib-omri.onrender.com`.

## 📱 الخطوة 3: استخراج ملف الـ APK وتثبيته على الموبايلين

عشان ماتحتاجش تنزل برامج ضخمة (Android SDK و Flutter بحجم 10 جيجا) على جهازك، جهزنا لك ملف بناء سحابي مجاني:

### الطريقة السحرية (عبر GitHub Actions - في 3 دقائق):
1. ارفع كود المشروع كاملاً إلى مستودع خاص (Private Repo) على حسابك في **GitHub**.
2. ادخل على تبويب **Actions** في صفحة المشروع على GitHub.
3. ستجد مهمة جاهزة اسمها **"Build Habib Omri APK"**، اضغط على **Run workflow**.
4. بعد حوالي 3 دقائق، ستنتهي المهمة وتجد ملف جاهز للتحميل باسم:
   👉 **`Habib-Omri-App.zip`** وبداخله ملف **`app-release.apk`**.
5. حمّل الملف وثبته على هاتفك وهاتف خطيبتك!
