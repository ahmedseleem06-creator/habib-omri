# مشروع تطبيق وموقع وكالة X Deal Marketing 🚀

تطبيق وموقع متكامل لوكالة **X Deal Marketing** (هاتف: `01021983866`)، يشمل نظام المحاسبة والأرباح للخدمات الـ 6، دليل العملاء وحساباتهم (CRM)، وصفحة باقات وعروض العملاء مع حاسبة التخصيص التفاعلية، وتطبيق موبايل كامل.

---

## 📁 هيكل المشروع (Project Architecture):

```
x_deal_marketing/
│
├── index.html                   # التطبيق الرئيسي التفاعلي (Responsive Web & Mobile App)
├── manifest.json                # إعدادات تثبيت التطبيق على الموبايل (PWA Standalone)
├── sw.js                        # سيرفس وركر لتشغيل التطبيق بدون إنترنت (Offline Mode)
├── logo.jpg                     # الشعار الرسمي للوكالة
│
└── flutter_app/                 # كود تطبيق الموبايل الأصلي (Native Flutter Project)
    ├── pubspec.yaml             # إعدادات الحزم والاعتمادات
    ├── assets/images/logo.jpg   # أيقونة التطبيق في الفلاتر
    └── lib/
        ├── main.dart            # نقطة البداية وإعدادات اللغة العربية والـ Theme
        ├── theme/app_theme.dart # الألوان النيون الداكنة المتناسقة مع الشعار
        ├── models/              # نماذج البيانات (العمليات، العملاء، العروض)
        │   ├── transaction_item.dart
        │   ├── client_item.dart
        │   └── service_offer.dart
        ├── services/            # الحفظ المحلي والتخزين (Storage & Seed Data)
        │   └── storage_service.dart
        └── screens/             # الشاشات الرئيسية
            ├── dashboard_screen.dart       # شاشة المحاسبة والأرباح الفورية
            ├── offers_screen.dart          # شاشة باقات وعروض العملاء
            ├── clients_screen.dart         # شاشة دليل العملاء والـ CRM
            └── add_transaction_screen.dart # تسجيل معاملة وحساب الربح التلقائي
```

## 📱 الخدمات الـ 6 المدعومة في الحسابات:
1. 🏪 **دعاية وباقات المحلات:** عقود شهرية، مطبوعات، وإدارة صفحات.
2. 🛠️ **صيانة الأجهزة والشبكات:** صيانة كمبيوتر، لابتوب، وأجهزة كاشير بالضمان.
3. 💻 **سمسرة بيع الأجهزة:** توفير لابتوبات استيراد فرز أول بأسعار الجملة.
4. 🤖 **اشتراكات الذكاء الاصطناعي:** حسابات ChatGPT Plus أصلية وتسليم فوري.
5. 📢 **إعلانات ممولة:** حملات مبيعات فيسبوك، انستجرام، وتيك توك مستهدفة.
6. 🎨 **تصميمات وهوية بصرية:** لوجو، منيو، وهوية سوشيال ميديا.

## 🚀 كيفية تشغيل وتثبيت التطبيق على الموبايل:

### الطريقة 1: التشغيل والتثبيت الفوري كتطبيق موبايل (PWA):
1. افتح ملف `index.html` في متصفح الموبايل (Chrome أو Safari).
2. اضغط على خيارات المتصفح (الثلاث نقاط) واختر **"إضافة إلى الشاشة الرئيسية" (Add to Home screen)** أو **"تثبيت التطبيق" (Install App)**.
3. سينزل التطبيق على شاشة موبايلك بأيقونته الرسمية المضيئة وبدون شريط عنوان المتصفح كتطبيق أصلي كامل!

### الطريقة 2: بناء تطبيق أندرويد (APK) عبر Flutter:
1. افتح مجلد `flutter_app` في Android Studio أو VS Code.
2. شغّل الأمر:
   ```bash
   flutter pub get
   flutter run
   ```
3. لاستخراج ملف التثبيت المباشر للأندرويد:
   ```bash
   flutter build apk --release
   ```
   ستجد ملف `app-release.apk` جاهزاً للتثبيت في هواتف العملاء أو الرفع على Google Play!
